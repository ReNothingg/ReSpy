# ReSpy

Бот сочетает обычный Bot API и сырой MTProto Business API. Обычные сообщения обрабатываются через aiogram, а одноразовые фото и события скриншотов перехватываются через MTProto до того, как Telegram удалит содержимое. Секретные чаты не относятся к Telegram Business и боту недоступны. Процесс должен работать постоянно.

```bash
python -m app.auth_user_session
```

## Что умеет

- хранить переписку независимо от того, остался ли чат в клиенте тг
- сохранять фото и другие доступные Bot API медиа сразу после получения и автоматически удалять локальные копии через 24 часа
- сохранять входящие фото «один просмотр» через MTProto и сразу присылать копию владельцу
- уведомлять о системном событии создания скриншота
- присылать удалённое сообщение, включая медиафайл, пока не истёк срок хранения
- показывать старую и новую версии изменённого сообщения
- отслеживать отправленные и полученные Telegram Gifts
- уведомлять об оплате апгрейда, вскрытии/превращении в уникальный подарок, передаче и перепродаже, если Telegram прислал соответствующее событие
- отмечать исчезновение сервисного сообщения подарка как неподтверждённое событие с возможными причинами, включая обмен на Stars
- проверять доступный список подарков получателя и сообщать, когда подарок исчез из инвентаря или снова появился
- показывать центр подарков с атрибутами, редкостью и полной хронологией
- давать поиск и фильтры в защищённой паролем веб-панели
- получать аватары через Bot API без сохранения на диске и показывать их рядом с чатами
- добавлять к уведомлениям кнопку архива чата и показывать количество сообщений, удалений, изменений и медиа
- принимать подключение только от владельца бота

### Встроенные плагины

- считать выражения через `/cal` прямо в любом диалоге
- включать `/mute` в диалоге, чтобы мгновенно удалять только новые сообщения собеседника и отключать звук чата. `/mute текст` оставит в чате только указанный текст без команды. `/unmute` вернёт прежние настройки уведомлений

## Запуск

1. Создайте бота у `@BotFather`.
2. В настройках бота включите **Business Mode**.
3. Скопируйте `.env.example` в `.env` и задайте:
   - `BOT_TOKEN`
   - `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` из `my.telegram.org`
   - свой числовой `OWNER_TELEGRAM_ID`
   - длинные `PANEL_PASSWORD` и `SESSION_SECRET`
   - публичный HTTPS-адрес панели в `PANEL_PUBLIC_URL`, чтобы кнопи открывались на мобиле.

Секрет сгенерировать так: `python3 -c 'import secrets; print(secrets.token_urlsafe(48))`

4. Запустите:

```bash
docker compose up -d --build
```

Или без Docker:

```bash
pip install -e .
python -m app.main
```

Срок хранения задаётся через `MEDIA_RETENTION_HOURS` (по умолчанию 24), период очистки через `MEDIA_CLEANUP_INTERVAL_SECONDS` (раз в час).
